# Canarias System — Project Scope

# Alcance General

El sistema contempla la construcción de una plataforma web integral para la gestión operativa, financiera y logística de Canarias S.R.L. y sus distintas sociedades comerciales.

El alcance inicial del proyecto incluye módulos administrativos, comerciales y operativos vinculados al negocio de ventas financiadas y cobranzas diarias.

---
