# Canarias System — Roadmap General

# Objetivo del Documento

Este roadmap define la planificación macro del proyecto Canarias System, incluyendo:

* fases de desarrollo
* objetivos
* entregables
* prioridades
* demos funcionales

El roadmap permite mantener alineados:

* equipo técnico
* cliente
* prioridades del negocio
* evolución del producto

---

# Duración General

## Tiempo estimado

12 semanas (3 meses)

---

# Metodología

* Desarrollo iterativo
* Micro-sprints
* Daily meetings
* Demos funcionales cada 15 días
* Validación continua con cliente

---

# FASE 1 — Fundamentos del Sistema

## Duración

Semanas 1–2

---

## Objetivo

Construir la base arquitectónica y operativa inicial del sistema.

---

## Backend

* Autenticación
* JWT
* Roles y permisos
* Gestión de usuarios
* Sociedades y Staff
* Swagger
* Arquitectura modular

---

## Frontend

* Login
* Layout principal
* Sidebar dinámica
* Dashboards base
* Rutas protegidas

## Entregable Principal

* Base multi-sociedad
