# Handoffs

Esta carpeta contiene las tareas formales entregadas a cada área del proyecto.

Los handoffs tienen como objetivo:

- reducir ambigüedad
- acelerar desarrollo
- mantener consistencia técnica
- documentar requerimientos reales
- facilitar escalabilidad futura

---

# Estructura

## backend-tasks

Documentación técnica entregada al equipo backend.

Incluye:

- módulos
- endpoints
- DTOs
- validaciones
- reglas de negocio
- arquitectura

---

## frontend-tasks

Documentación técnica entregada al equipo frontend.

Incluye:

- pantallas
- componentes
- formularios
- tablas
- integración APIs
- validaciones UI

---

## qa-tasks

Documentación de testing.

Incluye:

- casos prueba
- escenarios
- validaciones
- acceptance testing
