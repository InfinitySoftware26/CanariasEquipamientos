# Backend Tasks

Esta carpeta contiene las especificaciones técnicas backend.

Cada archivo representa un módulo funcional del sistema.

---

# Objetivos

- estandarizar desarrollo
- evitar inconsistencias
- mantener arquitectura modular
- reducir deuda técnica

---

# Estructura de cada handoff

Cada documento debe contener:

- contexto funcional
- entidades involucradas
- endpoints
- DTOs
- reglas de negocio
- validaciones
- responses
- permisos
- observaciones técnicas
