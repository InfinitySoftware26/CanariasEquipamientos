# Demo Sprint 03 – Sistema de Gestión Canarias

**Cliente:** Canarias S.R.L.
**Fecha:** 24/07/2026

---

# 1. Introducción (5 min)

## Bienvenida

Agradecemos nuevamente el tiempo brindado para esta nueva instancia de revisión del proyecto.

Durante este Sprint 03 el foco estuvo puesto en continuar consolidando el flujo comercial del sistema, incorporar nuevos módulos administrativos y validar junto al equipo de Canarias las reglas operativas que acompañarán el desarrollo del dominio de cobranzas.

## Objetivo de la reunión

Esta reunión tiene como objetivo:

* Presentar los avances desarrollados durante el Sprint 03.
* Validar los nuevos módulos incorporados.
* Confirmar el funcionamiento del flujo comercial implementado.
* Relevar nuevas necesidades operativas detectadas por el equipo de Canarias.
* Definir prioridades para la siguiente etapa de desarrollo.

## Alcance Sprint 03

Durante este sprint se desarrollaron los siguientes módulos:

### Gestión de Empleados

* Alta de empleados.
* Edición.
* Activación y desactivación.
* Administración por roles.
* Jerarquía de creación de usuarios.

### Gestión de Zonas

* Alta de zonas.
* Edición.
* Administración de zonas.
* Preparación para asignación de recorridos.

### Evolución del Flujo Comercial

Se continuó la construcción del flujo operativo de ventas incorporando nuevas validaciones y transiciones entre perfiles.

### Experiencia de Usuario

Se presentó el comportamiento estándar definido para toda la plataforma.

Incluyendo:

* Validaciones visuales de formularios.
* Confirmaciones para acciones críticas.
* Mensajes de error.
* Consistencia visual entre módulos.
