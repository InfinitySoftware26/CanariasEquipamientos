# Client Business Rules

## Alta de Cliente

Un cliente puede ingresar al sistema mediante una solicitud de venta.

## Canal Seller

Cuando un SELLER registra una venta:

- debe completar los datos del cliente
- el sistema crea el registro del cliente
- la información queda pendiente de validación administrativa

## Validación

ADMIN verifica:

- datos personales
- teléfono
- domicilio
- documentación disponible

## Resultado

El cliente queda asociado a la venta creada.
